**Goal:** In `sonic-buildimage`, deliver (1) the `NhtEvent` JSON schema + encode/decode + C-API for the `sonic-fib` library; (2) the `RTM_NEWNHTEVENT` (6000) message assembly in `dplane_fpm_sonic.c` — providing a shared dependency for sonic-frr and sonic-swss.
**Architecture:** Extend the existing `render_schema.py` (add new functions + branches, **without modifying the original functions**) + add 3 Jinja2 templates to generate the `NhtEvent` class; the C-API `nht_event_encode()` is called from the FRR side; the FPM provider serializes `DPLANE_OP_NHT_EVENT_UPDATE` into a netlink message.
**Tech Stack:** C/C++, Python (Jinja2), autotools, netlink, libnl.

**Dependencies:** None (this plan is a prerequisite for B and C).
**Corresponding spec:** [`ribfib-convergence-sonic-fib.md`](../../convergence-lld/ribfib-convergence-sonic-fib.md) (NhtEvent encode/decode library) + [`ribfib-convergence-dplane-encoding.md`](../../convergence-lld/ribfib-convergence-dplane-encoding.md) (FPM message assembly)
